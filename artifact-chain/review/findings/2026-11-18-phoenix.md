## F1 (P1) — Rework-round definition undercounts

`RSI.md` says: "A rework round is one findings file followed by a fix push
that still leaves findings open."

Read literally, a PR that takes exactly one findings file plus one
fully-fixing push scores 0 rounds — the same as a PR that needed no fixes
at all. This is the loop's only outcome metric; the definition must count
one review→fix cycle as 1 round whether or not the push closes everything.
Fix: reword to "one findings file followed by its fix push — one
review→fix cycle — whether or not that push closes everything", with
0 rounds = merges after the first review with zero findings and 1 round =
one findings file + one fix push.
